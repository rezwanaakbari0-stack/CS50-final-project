# StudyHub

Flask + HTML + CSS + JavaScript + Python (SQLite)

## اجرا
    python -m venv venv
    source venv/bin/activate        # ویندوز: venv\Scripts\activate
    pip install -r requirements.txt
    python app.py

بعد در مرورگر باز کن: http://127.0.0.1:5000

پیام‌های فرم تماس در فایل messages.db ذخیره می‌شوند.
