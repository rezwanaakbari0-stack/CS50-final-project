Educational Self-Study Platform

Description

This project is an educational self-study platform developed as my CS50 Final Project.

The platform provides students with free access to educational courses and learning materials without requiring them to create an account or register.

Students can explore different subjects, study independently, and gain knowledge at their own pace.

Unlike traditional online learning platforms that focus on formal course completion and certificates, this platform focuses on independent learning, self-education, and making educational information accessible to everyone.

If students experience any problems or have questions, they can contact the platform administrator through the Contact page.

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

Main Features

- Access educational courses without registration.
- Explore educational content independently.
- Learn at your own pace.
- Contact the administrator through the Contact page.

Project Goal

The goal of this project is to make educational resources more accessible and encourage independent learning.
